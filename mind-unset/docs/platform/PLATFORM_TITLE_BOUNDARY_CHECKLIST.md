# Platform/Title Boundary Checklist

Status: Mandatory
Date: 2026-04-18

## Core Boundary

- NeuralBook = platform
- MindUnset = title

## Buyer-Facing Language Rules

- Buyer-facing copy must not confuse NeuralBook and MindUnset.
- Platform docs may discuss NeuralBook as reusable infrastructure.
- MindUnset Gumroad page should discuss MindUnset as the interactive desktop app.
- Do not use stale OS/runtime/Sovereign product framing in buyer-facing surfaces.

## Pre-Publish Checklist

- [ ] Landing page calls the product MindUnset where user buys
- [ ] Platform capability claims are labeled as NeuralBook platform features
- [ ] SKU pages avoid mixing platform architecture terms into buyer value copy
- [ ] Docs distinguish platform-level and title-level responsibilities
- [ ] Screenshots/captions use correct product naming
- [ ] Support macros/templates follow boundary language

## Copy QA Examples

Correct:

- MindUnset is the interactive desktop app experience delivered to end users.
- NeuralBook is the underlying platform framework used to build and operate titles.

Incorrect:

- MindUnset is the platform runtime framework for all Sovereign products.
- NeuralBook app purchase unlocks MindUnset platform ownership rights.
